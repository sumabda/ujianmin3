Tujuan Import

Mapel, kelas, dan bobot default dipakai bila tidak tercantum di file.

Soal hasil import tidak langsung terbit. Tinjau pratinjau, koreksi bila perlu, lalu setujui untuk menyimpan ke bank soal.

Tarik file .xlsx / .xls ke sini
atau klik tombol Pilih File Excel di atas. Sistem membaca isi file secara otomatis.

Kolom template: Nomor Soal, Pertanyaan, Pilihan A, Pilihan B, Pilihan C, Pilihan D, Kunci Jawaban, Jenis Soal, Bobot Nilai, Pembahasan. Kolom Mata Pelajaran dan Kelas opsional.

Tarik file .docx ke sini
Soal bernomor (1., 2., ...) dengan pilihan A–D dibaca otomatis, termasuk kunci jawaban. Kunci dikenali dari "Kunci: B" / "Jawaban: B" di akhir soal, atau dari blok Kunci Jawaban di akhir dokumen (contoh: 1. A  2. B  3. C atau tabel No | Kunci).

Tarik file PDF atau gambar ke sini
